# JARVIS 1 — Fresh Complete Build

Features: blue reactor HUD, Ollama AI, memory, voice input/TTS, wake-word
helper, Windows controls, web search/opening, WhatsApp with confirmation,
camera preview, and modular architecture.

Install:
    pip install -r requirements.txt

Start Ollama in one terminal:
    ollama run llama3.2:1b

Start JARVIS in another:
    python main.py

Edit data/contacts.json before using WhatsApp.
Dangerous actions require explicit confirmation.
